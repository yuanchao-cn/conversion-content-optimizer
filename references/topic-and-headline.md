# 选题、标题与开篇

来源：《商业内容创作实战手册》通用方法论部分。只含通用写作原理，不含热度/CTR 等时效指标与工具操作。

## 一、选题：问题三分类

用户带着什么问题来，决定内容该怎么写。

| 类型 | 特征 | 适配场景 | 内容要点 |
|---|---|---|---|
| 精准类（含品牌/产品词） | 用户已锁定对象 | 品牌已有声量、需要拦截精准流量 | 直接对比与说服，转化意图强 |
| 品类问题（含品类/功效/场景词） | 用户有需求未定品牌 | 带货导向首选 | 讲清怎么选、标准是什么，承接需求 |
| 人群向泛生活问题 | 场景宽、受众广 | 需要唤起潜在需求 | 前提是受众足够广，能把兴趣阅读唤醒成需求阅读 |

**选题优先级**：带货导向优先选品类问题；精准问题在品牌已有声量时再补。

## 二、标题

### 标题四特性
- **稳定性**：不依赖短期热点，长期有效。
- **定语指向性**：限定人群/场景，读者一眼知道是不是写自己。
- **可复用性**：同一结构能迁移到同品类其他选题。
- **周期性**：节点型选题会周期性变热、回落，提前布局。

### 五种标题技巧
| 技巧 | 做法 |
|---|---|
| 强反差 | 现状 + 方案 + 放大结果，制造认知落差 |
| 大场景 | 放宽适用人群，扩大相关性 |
| 贴标签 | 限定具体人群，增加代入感 |
| 借势 | 关联已被用户熟悉的人/事/物（注意合规与相关性） |
| 强调式 | 用数字、符号突出关键信息 |

**核心判断**：真正抓人的标题 = 专业度 + 场景感 + 顺应人性，不是越夸张越好。标题承诺必须与正文一致。

## 三、开篇

### 三种引导（可组合使用）
- **利益引导**：低成本 / 短周期 / 高收益。
- **背书引导**：个人经验、背景、专业身份。
- **观点引导**：先给一个鲜明判断。

### 组合公式（按需取材，不必全用）
需求场景 + 自报家门 + 最小成本 + 经验效果 + 形象化比喻 + 关联熟悉事物 + 前后对比 + 数字体现。

### 篇幅铁律
开篇前段（大致几百字量级）内交代完「困境 + 现状 + 遇见产品」并引出转化引导。若「遇产品前的铺垫」超过全篇一半，属于本末倒置——这是最高频的开篇失败模式之一。

> 注：手册给的字数阈值属于经验参考，不是硬指标；诊断时用「铺垫是否喧宾夺主」的结构判断，不机械卡数字。
