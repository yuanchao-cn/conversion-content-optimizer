# 内容行业判断

## 目的

在优化之前先确定内容所处行业，因为不同行业的证据标准、合规红线和转化路径差异很大。
判断结果用于：选择同类案例、套用合适的证据标准、识别不能碰的承诺。

## 判断信号（按优先级）

| 信号 | 提取方法 | 示例 |
|---|---|---|
| 品类词 | 正文高频名词、型号、成分、参数 | 「800ml 不锈钢饭盒」「复合材料拉杆箱」 |
| 使用场景 | 动作、地点、时间、频率描述 | 「通勤带饭」「出差登机箱」 |
| 受众身份 | 称呼、痛点归属、身份标签 | 「新手妈妈」「租房党」「考研人」 |
| 竞品与渠道 | 提到的对比对象、购买渠道 | 「某米」「天猫旗舰店」 |
| 监管敏感词 | 功效、承诺、资质类词汇 | 「根治」「100%有效」「收益保证」 |

## 置信度规则

- **高**：≥3 类信号一致指向同一行业，且无冲突信号。
- **中**：2 类信号一致；或信号较多但有 1 个弱冲突。
- **低**：≤1 类信号，或信号互相矛盾。低置信度必须向用户确认，不能自行拍板。

## 输出格式

```
行业判断：<行业名>（置信度：高/中/低）
依据信号：
- 品类词：<原文摘录>
- 使用场景：<原文摘录>
- 受众身份：<原文摘录>
待确认：<若有冲突信号，列出需要用户澄清的点>
```

## 常见行业与关注点

| 行业 | 证据重点 | 合规/承诺红线 |
|---|---|---|
| 知识付费/教育 | 效果案例、课程体系、师资 | 不承诺「必过」「保就业」「必提分」「包赚」「无门槛」「全额退款」；收益展示注意脱敏；素材需授权、涉竞品描述克制 |

> 判定为教育 / 知识付费 / 培训（升学考研、语言启蒙、职业技能、副业技能等）时，标记「教育补充适用」并在 Step 4 读取 `@references/education-content.md`，按 E1–E9 补充检查；教育专章只在此时出现。
| 美妆个护 | 成分机制、真人过程证据 | 不承诺医疗级功效 |
| 3C数码/家电 | 参数换算成场景利益、实测细节 | 不虚构跑分/续航数据 |
| 母婴 | 安全资质、真实使用场景 | 不替代医疗建议 |
| 健康 | 机制解释、适用边界 | 不承诺疗效、不替代就医 |
| 本地生活 | 具体门店/价格/路线 | 不虚构优惠与库存 |
| 企业服务 | 客户案例、ROI 逻辑 | 不虚构客户名单与数据 |
| 金融 | 风险提示、适用性 | 不承诺收益、不诱导交易 |

## 注意

- 行业判断不是标签分类作业：判断不出就问，不要用最常见行业套。
- 跨行业内容（如「母婴+健康」）以**转化目标对应的主行业**为准，并在报告里注明次行业。
