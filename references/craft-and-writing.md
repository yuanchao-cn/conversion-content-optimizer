# 创作手法：痛点、表现力、真实感与结构

来源：《商业内容创作实战手册》通用方法论部分。只含通用写作原理，剔除 CTR、赞评数、配图数量、吐司等时效指标与工具。

## 一、痛点与亮点

### 挖掘痛点：三个阶段的阻碍
从 **购买 → 使用 → 效果** 三阶段找用户卡在哪。五个要素：**性能效用、容易程度、价格、形象、安全**。

教育/长决策类可按用户进阶阶段拆：入门难 → 提升难 → 突破难 → 扩张难，每阶段呈现的重点不同（结果前置 / 过程与后果 / 场景与情绪 / 价值放大）。

### 亮点挖掘
**确认痛点 → 传达亮点**。痛点 = 行动前的最大阻碍；亮点 = 满足欲望的东西。
常见角度：解决具体问题、优化性能、性价比、独特原理、权威或口碑背书、品牌优势。

## 二、表现力

### 四类问题与修法
| 问题 | 修法 |
|---|---|
| 只说论点不说论据 | 按「论点 → 论据 → 修辞」写；修辞可省，论据不可省 |
| 修辞不到位 | 用 5W2H 检查：时间、地点、为什么、因为什么、导致什么问题、如何解决、多严重、关联谁 |
| 混淆受众、晦涩 | 精简术语，改用拟人、比喻、类比 |
| 卖点表述不清 | 追问「对自己/对他人有什么好处」，拆出直接、间接、低成本效果 |

### 提升表现力六招
1. 定语言风格（如美妆活泼、数码科普）；
2. 表达多样化：五感 + 氛围感 → 代入感；
3. 覆盖关键点且语言精炼；
4. 合理配图辅助说明；
5. 反复强化重点；
6. 留白：短句与分段让视线有停顿处。

### 修辞练习法
加参照物对比 → 加具体数字/时间 → 加排比（细节、状态、类比、时间）。

## 三、真实感

### 三类常见问题
| 类型 | 表现 | 修法 |
|---|---|---|
| 人设类 | 无人设/人设弱、人设不符、强拗人设 | 开头立人设并用生活场景引入；人设与品类匹配；换回作者能驾驭的笔调 |
| 细节类 | 机械化描写、设定靠叙述不靠佐证 | 用五感（看/听/尝/闻/触）；细节越细读者用脑越少；对话用朴实口语 |
| 素材类 | 图模糊、硬广图、与人设不符 | 真实取景、真人实拍、借鉴图二次加工且有版权 |

### 具象化 3W 模型
把抽象词（如「舒服」）联想到具体场景：**WHO**（谁用）/ **WHERE**（在哪）/ **WHAT**（做什么）。

### 图片的四类作用
解释说明、留白、渲染情绪、促进销售。配图原则：真实取景、人设统一、有版权、效果对比不做在一张图里；不涉低俗、隐私或敏感肖像。

## 四、结构与排版

### 底层结构：总分总
总（提观点）→ 分（分论点 + 论证 + 小结，可多组）→ 总（结尾）。
- 观点是肯定判断 → 从重要性/必要性论述；
- 观点是否定判断 → 谈原因或危害性。

### 三种结构模式
1. 观点 + 一人多故事；
2. 大观点 + 多产品；
3. 大观点 + 多小观点。

### 两类常用模板
- **亲历者结构**：经历/问题 → 试错若干例 → 引出产品（背书 + 体验）→ 产品描述（一个特点一段，多用「我」少用「你」）→ 产品效果（前后对比）→ 结语。
- **专家结构**：开篇立人设与价值 → 必要性分析 → 原理科普 → 测评指标 → 测评结果 → 产品推荐（适配人群 + 参数 + 优缺点）→ Q&A → 结语。

### 板块拆分法
- **时序法**：按时间阶段拆（如第一周/第一个月、备考各阶段）。
- **事序法**：按维度拆（五感、成分、多角度）。

### 排版细节
- 用有序/无序列表，句后加标点；强调靠变色/加粗，一屏内不要过多；
- 中文直角引号「」、中文省略号……；中英文间留一个空格；
- 分段短、句子短、多小标题；长文把目录前置；分割线提示阅读进度。

## 五、二次创作

适用短期大量产出；难靠二创打造爆款。五步法：
1. 选结构清晰、表现稳定的对标内容；
2. 拆解其结构与关键段落（像素级理解）；
3. 扒该垂类的高频关键词（参考多篇同类）；
4. 汇总整合模仿（A 的选题 + B 的结构 + C 的关键词）；
5. 按同等位置替换配图。

**核心认知**：爆款的本质是重复——相似的结构和表述大概率再奏效一次。但二创不等于照抄，需保留自己的真实证据与人设。
