# 对标检查清单

逐项判定：**命中 / 部分命中 / 缺失 / 不适用**，每项必须附原文摘录；判为「不适用」要写原因。
案例对比写「案例怎么做 → 本文怎么做 → 差距」，不写空泛评价。

## 一、10 维检查表

| # | 维度 | 要检查什么 | 判定为「命中」的最低标准 |
|---|---|---|---|
| 1 | 标题与首屏 | 利益点是否具体、是否与正文一致 | 标题含具体利益/场景，开篇几句说清相关性 |
| 2 | 痛点具象度 | 是否写清场景、频率、后果或成本 | 至少 2 个具体细节，能用原文摘录证明 |
| 3 | 证据强度 | 数据/过程/案例/资质是否可验证 | 有可摘录的证据，且与主张直接对应 |
| 4 | 机制解释 | 方案为什么有效是否说清 | 给出因果链或原理，不只是结果描述 |
| 5 | 差异化 | 与常见替代方案的区别 | 明确指出对比对象与差异点 |
| 6 | 门槛消除 | 价格/时间/风险/操作门槛是否处理 | 至少处理一个主要门槛且有具体说法 |
| 7 | CTA 单一性 | 是否存在一个明确主行动 | 只有一个主 CTA，动作与位置清楚 |
| 8 | 行动成本 | 是否说明下一步要付出什么 | 明确时间/金钱/步骤成本 |
| 9 | 风险逆转 | 是否有兜底或保证 | 有可执行的风险降低说法（非过度承诺） |
| 10 | 可读性 | 段落、小标题、信息密度 | 段落短、小标题能独立表意、无连续大段 |

> **评论区**（输入带评论时才评，对应 N21）：正文之外还需看评论区氛围与前排引导——见下方「评论区场域专项」；无评论输入时整项判「不适用」，不扣分。

## 二、转化引导专项检查

转化引导指内容中把用户从「读」推向「做」的那段文字与位置安排，不依赖任何特定平台组件。逐项检查：

| 检查点 | 要检查什么 | 命中标准 |
|---|---|---|
| 出现时机 | 是否在第一次讲到产品之后、理由已开始铺陈处出现 | 首次提到产品附近有承接，不是凭空出现 |
| 前置事件来源 | 是否交代「怎么得知/为什么用它」，让转折自然 | 有可摘录的来源句，不是硬推 |
| 人群匹配 | 引导文案是否点名适用人群 | 能摘录到人群指向 |
| 思考成本 | 是否替用户降低理解与决策成本 | 一句话说清为什么适合 |
| 痛点具象化 | 是否呼应前文具象痛点 | 与前文痛点形成回扣 |
| 权威证明 | 是否有可验证的背书或事实证明 | 有背书且与主张对应 |
| 过渡自然 | 是否承上启下，不打断阅读 | 有转折句，不是突兀插入 |
| 下单引导 | 是否给出明确的下一步动作 | 动作清楚、可执行 |

**位置原则（按内容性质选，不是统一模板）**：
- 强信任型（干货、故事、测评向）：转化引导后置，先建立信任再引导；
- 常规型：放在前中部，与内容自然融合；
- 强情绪/种草型：可前置，用利益或场景迅速唤起兴趣。

> **更新（以 `methodology-refresh-2026.md` 第三节为准）**：更精确的判据是「用户此刻的需求状态」——精准意向承接（搜索/垂类决策）可前置结论，兴趣激发场景过早暴露意图易适得其反；倾向只保留一个主入口，反复铺设营销感过强；转化前需补权威感与真实感两类铺垫；过早暴露不仅点击低还可能引发负反馈影响分发。
>
> 注：手册原文给出的「卡片密度、字数、数量」等属于平台工具时代的经验值，已剔除，不作判定依据。判断只依据上述逻辑是否成立。

## 二·补、评论区场域专项（无评论输入则整节不适用）

> 评论区是「社会证明 + 异议化解 + 临门一脚」的第二现场。仅当输入确实带评论区时逐项判定，每项附评论原文摘录；无评论时写「未提供评论区，本节不适用」，不扣分、不臆测。

| 检查点 | 要检查什么 | 命中标准 |
|---|---|---|
| 前排定调 | 前排/热评是否在验证主张、提出关键疑问或给出具体场景 | 前排有具体的正向体验/关键追问/使用场景，不只是情绪表态或跑题 |
| 作者回复 | 作者（或有身份账号）是否回应高价值问题并给落点 | 回复了价格/适配/风险/去哪做等具体问题，且导向下一步，不止「谢谢支持」 |
| 异议化解 | 同类疑问是否被正文或评论回复集中解答 | 反复出现的疑问有对应解答，回应可信、具体 |
| 氛围状态 | 整体氛围是正向热络/质疑/冷清/跑题 | 质疑有可信回应；冷清有引发讨论的钩子；不跑题失焦 |
| 正文—评论呼应 | 正文承诺在评论有无验证、正文疑虑在评论有无补齐 | 形成「正文提主张→评论验证/答疑」的闭环 |

**处置映射**：同类异议扎堆却无人答 → P1（把高频疑问前置正文或在评论回复集中解答）；质疑居多且无可信回应 → P0/P1 候选；前排空泛或跑题 → P1（补具体引导）；作者回复仅客套 → P2。所有建议仅在合规范围内（补充真实信息、回复真实疑问、前置真实高频问题），**不得虚构好评或给出刷评/买评/诱导好评等违规手法**。

## 二·补2、教育行业补充专项（仅判定为教育/知识付费/培训时读）

> 仅 Step 2 判定为教育行业时适用；非教育行业整节跳过。完整方法论与 E1–E9 检查点见 `@references/education-content.md`。核心教育专有判断：搜索/推荐入口错位（E1，可 P0）、信任来源配比（E2）、原生标题与价值外显（E3）、开头三件事（E4）、需求缺口（E5）、钩子成本与引导语（E6）、配图与节奏（E7）、全链路一致（E8）、合规红线（E9，可 P0）。
> 合规提醒：评论区只做筛选/置顶/回复真实问题/折叠攻击性评论；控评、水军、虚假互动一律禁止，与下方「操纵评论区」反模式一致。

## 三、常见反模式（命中即列为 P0 或 P1 候选）

### 通用反模式
- **自嗨形容词**：「效果好、品质卓越、行业领先」但没有证据或场景。
- **伪痛点**：提问看似痛点，答案却是产品功能介绍，没有承认用户真实处境。
- **证据错位**：用品牌大事记证明某个具体功效。
- **多 CTA 竞争**：结尾同时出现关注、私信、购买、加群，主目标被稀释。
- **CTA 前置**：理由还没给完就要求行动，用户缺乏决策依据。
- **过度承诺**：「100%」「根治」「必赚」「绝对」——按行业红线处理，必须改。
- **信息搬运**：大段参数/术语堆砌，没有翻译成用户利益。
- **虚假紧迫**：虚构库存、限时、名额，无证据支持时一律删除或标注待证实。
- **操纵评论区**：虚构用户好评、刷评买评、诱导好评，或以话术伪装真实反馈——一律不进入改写建议，只用合规的真实信息补充与回复。

### 表现力反模式（来自手册）
- **只有论点无论据**：按「论点 → 论据 → 修辞」修补，论据不可省。
- **修辞空转**：形容一堆但 5W2H 要素缺失，读者脑中无画面。
- **术语晦涩、受众错位**：不精简术语，混淆目标人群。
- **卖点表述不清**：只说功能，不答「对我有什么好处」。

### 真实感反模式（来自手册）
- **人设弱/不符/强拗**：无人设、人设与品类冲突、滥用网络热词冒充口吻。
- **机械化描写**：细节靠叙述而非五感佐证，设定无细节支撑。
- **素材失真**：图模糊、硬广感、与人设不符、无授权。
- **铺垫喧宾夺主**：遇产品前的铺陈超过主体，产品与利益点迟迟不出场。

## 四、与案例库配合

- 同行业/同目标案例优先；没有则用跨行业但结构相似的案例，并注明「跨行业类比」。
- 一个维度最多引用 1 个案例，避免把报告写成案例摘录合集。
- 案例的 KnowHow 必须写成可迁移的动作描述，不能只写「这个案例写得很好」。
