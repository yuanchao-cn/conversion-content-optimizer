# 营销目标确认

## 目的

目标决定内容结构、证据类型和 CTA 写法。目标没确认就优化，容易把「留资内容」改成「下单内容」，方向完全相反。

## 目标分类与内容含义

| 目标 | 典型 CTA | 内容应强化 | 不应强化 |
|---|---|---|---|
| 留资 | 留手机号/加企微/领资料 | 资料价值、领取门槛低、隐私安心 | 逼单式库存话术 |
| 咨询 | 私信/预约评估/问客服 | 问题诊断感、专家感、响应预期 | 冗长产品 enumerate |
| 下单 | 购买/领券/去店铺 | 利益具体、价格锚点、风险逆转 | 过度科普冲淡行动 |
| 关注/涨粉 | 关注账号/订阅专栏 | 持续价值、人设辨识度 | 单一强推转化 |
| 下载/注册 | 下载 App/开账号 | 使用路径短、即时收益 | 复杂功能罗列 |
| 私信 | 发关键词/回复数字 | 互动指令极简、反馈即时 | 多步操作 |
| 品牌认知 | 无强 CTA | 主张清晰、记忆点、情绪 | 生硬促销 |

## 从内容推断目标的规则

1. 找全文所有行动指令（含按钮文案、结尾引导、评论区引导）。
2. 有多个指令时，**取位置最靠后且最具体的那个**作为主目标；其余记为次目标。注意：「位置最靠后」用于判定主目标，与检查清单「CTA 前置」反模式不冲突——前者定主次、后者评布局；两者分别记录，不要互相覆盖。
3. 找不到行动指令时，按内容主体判断：教程/清单偏「关注或留资」，测评/对比偏「下单」，诊断/评估偏「咨询」。
4. **前置课/训练营/直播课类**：「听完课后申请加入/报名」若最终导向付费课程或渠道名额，按「留资」推断（先加微信/报名再转化），并在假设里写明「若实际目标是课程下单，P0 的 CTA 收敛方向会相反」；不要默认为「下单」。
5. **清单与测评属性冲突时**：当内容既是清单又是测评（如"按 X 筛选的横向清单"），规则 3 的「清单偏关注/留资」与「测评偏下单」会同时成立。裁决顺序：① 看是否有品牌/商品导购意图（多 SKU 对比、品牌内选品）→ 偏「下单/导购」；② 无导购、纯客观科普 → 偏「关注/品牌认知」；③ 仍难判 → 按「下单/导购」推断但置信度标「中偏低」，并在报告和「待用户确认」里明确列出另一可能（纯品牌认知），说明若目标不同则 CTA 建议方向相反。不要静默取其一。
6. 推断结果必须标为「推断」，不要写成用户已确认。

## 问法（最多一个问题）

只在以下情况问用户，且一次只问一句：
- 内容存在两个及以上目标且难以判断主次；
- 完全没有 CTA，且内容形态无法推断；
- 用户明确说「目标你自己定」但推断置信度低。

推荐问法：「这篇内容最希望用户做完哪一步：留资、咨询、下单，还是关注？选一个主目标我就按它优化。」

用户不回答时：按推断规则取主目标，在报告里写「目标为推断，若实际目标不同请告知，我按新目标重做 P0 建议」。

## 输出格式

```
营销目标：<目标名>（已确认/推断）
依据：<原文 CTA 摘录 或 推断理由>
次目标：<若有>
假设：<若为推断，写明假设与影响>
```
